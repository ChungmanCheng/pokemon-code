# Change Log
All notable changes to the "pokemon-code" extension will be documented in this file.

## [2.1.0] - 2026-10-07

- Add persistent trainer and Pokémon XP, levels, and encounters from human and coding-agent edits.
- Run battles, partner selection, skills, and captures automatically while coding continues.
- Add automatic evolution across all 72 paths in the original 151 Pokémon, including existing saves and new captures. Level evolutions use normal thresholds; stone and trade evolutions happen at level 36, with Eevee choosing its branch automatically.
